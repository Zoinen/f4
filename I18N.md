# Localization (i18n) & Help System in f4

`f4` features a flexible, declarative localization system that allows translating both the user interface and the help files without recompiling the application.

## 1. How it works (The Fallback System)

To ensure the binary remains a single, portable executable, `f4` embeds the default English language (`en.lng`) and English help file (`en.hlf`) directly into the compiled application.

When `f4` starts, it follows this loading sequence:
1. Loads the embedded English strings.
2. Checks the user's `Language` preference in the configuration.
3. If the language is not English, it looks for an overriding `<language_code>.lng` file on disk.
4. Overlays any found translated strings on top of the English ones. If a translation is incomplete, the missing strings will safely fall back to English.

### Directory Structure
Language and help files are searched for in the following locations (in order of priority):
1. User profile: `~/.config/f4/lang/` and `~/.config/f4/help/` (or `%APPDATA%\f4\...` on Windows).
2. Portable app directory: `./lang/` and `./help/` relative to the `f4` executable.

## 2. Interface Translation (`.lng` files)

Language files use a standard INI format.

*   **`[Language]` section**: Contains metadata (Name, Code, Author). This is used to populate the Language selection menu (`F9 -> Options -> Language`).
*   **`[Strings]` section**: Contains the key-value pairs for the UI.

**Example `es.lng` (Spanish):**
```ini
[Language]
Name=Español
Code=es
Author=Translator Name

[Strings]
vtui.Ok=&Aceptar
vtui.Cancel=Cancelar
Menu.Files=Archivos
Quit.Confirm=¿Quieres salir de f4?
```
*(Note: Use `&` to define the keyboard shortcut/hotkey for a label or button. To display a literal ampersand, use `&&`)*.

## 3. Help File Translation (`.hlf` files)

Help files use a lightweight, Markdown-inspired format natively parsed by the `vtui` framework.

*   `@TopicName` defines a new help page anchor.
*   `$Sticky Title` defines a header that stays at the top of the screen while the user scrolls.
*   `~Link Text~TargetTopic@` creates a clickable hyperlink to another topic.
*   `#Bold Text#` highlights text.

If `f4` cannot find the help file for the current language (e.g., `es.hlf`), it will automatically fall back to the embedded `en.hlf`.

## 4. The Translator Tool (`Ctrl+Alt+RightClick`)

To make translating `f4` as easy as possible, the application includes a built-in reverse-lookup tool for developers and translators.

If you see a string in the UI and want to know its translation key, simply hold **`Ctrl + Alt` and `Right-Click`** on the element (button, label, menu item, etc.).

`f4` will:
1. Perform a hit-test to find the exact UI component under your mouse.
2. Extract its current text.
3. Reverse-lookup the text in the active dictionary to find its `Key`.
4. Traverse the UI tree upwards to build a "Help Context" stack.
5. Copy a formatted report directly to your system clipboard.

**Example Clipboard Output:**
```text
--- f4 Translator Tool ---
Key:  PanelSettings.ShowHidden
Text: Show hidden and system files
Help Context: Panels -> Panel settings
```
You can then open your `.lng` file, search for `PanelSettings.ShowHidden`, and translate it.
