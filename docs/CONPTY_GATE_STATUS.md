## Три свойства ТЗ

- Побайтовая история: `dir /s /b`, 23 906 строк, `mismatch=0` при ширине
  захвата 256, 320, 384 и 512; рабочее значение — 512.
- Динамический reflow: шесть смен ширины потребителя посреди потока, SHA
  истории неизменен.
- Устойчивость: произвольные границы чтения в транспортном и логическом
  слоях, вытеснение с сохранением строки из 257 символов, 300/300 seed-сессий,
  1 500 consumer-проверок, ошибок 0.

## Условия и ограничения

Результат относится к pinned host с проверкой личности, ширине захвата 512,
без `--vtmode` и без `PSEUDOCONSOLE_INHERIT_CURSOR`. Полноэкранные программы
историю не оставляют. Если ребёнок выключает DECAWM, хост теряет хвост строки.
При видимом курсоре перенесённая строка может разорваться на границе кадра;
широкий захват устраняет этот класс для проверенных команд.

Host-resize остаётся неактивным в рабочем B1-0 пути; `--resizeQuirk` проверялся
только отдельным диагностическим сравнением со сужением окна. Следующий этап —
отдельная интеграция в f4, не часть gate.
