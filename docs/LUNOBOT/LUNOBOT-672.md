# Лунобот-2: PR #672 — отчёт покрытия

## Статус

PR обновлён поверх актуального `main` после устранения конфликтов и объединён
в `main` коммитом `508bbea5`.

Первый CI после обновления прошёл по сборкам, тестам, race и lint, но остановил
`Quality / Run actionlint`: shellcheck обнаружил `SC2086` в намеренном разборе
двух флагов покрытия. Флаги теперь сначала разбираются в массив через
`read -r -a`, после чего передаются как отдельные аргументы без неэкранированного
word splitting. Повторный CI run `34183098827` завершился успешно; три OS-
профиля (`linux`, `macos`, `windows`) были поставлены Codecov в очередь.

## Решение

- Сохраняется текущая матрица `test` из `main`: affected-package отбор,
  перемешивание тестов, разбиение macOS/Windows на shard-ы и отдельная проверка
  `TestAllDialogs_LayoutValidation`.
- Профиль покрытия создаётся только в Linux/amd64 и в обоих shard-ах macOS и
  Windows; shard-ы одной ОС используют один Codecov flag, чтобы их данные
  объединялись.
- Загрузка профиля выполняется только если профиль создан. Codecov остаётся
  informational и не может сделать CI красным из-за отсутствующего токена или
  ошибки загрузки.

## Инварианты

- Покрытие не меняет набор тестов, порядок проверки affected packages или
  платформенный охват матрицы.
- `-coverpkg=./...` учитывает покрытие импортируемых пакетов, а
  `disable_search` не позволяет Codecov принять файл перевода
  `coverage_baseline.txt` за профиль Go.
- Локальные сборки и тесты не выполняются; перед публикацией проверяется только
  `git diff --check`, а результат компиляции и CI подтверждается GitHub Actions.
