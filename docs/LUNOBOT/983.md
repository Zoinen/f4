## Решение и инварианты

Настроенная привязка владеет совпавшим событием независимо от того, удалось ли
команде выполнить действие. Отказ команды не должен повторно запускать
обработку той же клавиши в `PanelsFrame` или другом нижележащем кадре.

Это сохраняет нормальный fall-through только для клавиш, для которых вообще не
нашлось настроенной привязки. Для явной привязки `None` прежнее подавление
события также сохраняется.

## Проверка

Локальные сборки и тесты не запускались по инструкции Лунобота. Регрессионная
проверка добавлена в `cmd/f4/macro_test.go`; полная проверка должна выполняться
через GitHub Actions для точного SHA PR.

## Дополнительное исправление

После объединения PR #986 оставался второй сценарий: plugin-диалоги могли
помещаться не на экран запросившего их `PanelsFrame`, а команда добавления в
архив принимала синтетическую строку `..` как цель. Сообщения, поля ввода и
меню plugin-команд теперь привязываются к исходному workspace, а `..`
отбрасывается до открытия окна архива. Добавлена регрессионная проверка
`TestActionAddArchiveIgnoresParentDirectoryRow`.
