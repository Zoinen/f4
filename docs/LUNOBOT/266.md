# Issue #266 — смешанные атрибуты в выделении

## Задача

При открытии свойств нескольких файлов чекбокс должен показывать `?`, если
соответствующий атрибут различается у выбранных объектов. Если оставить `?`
при сохранении, этот атрибут не изменяется ни у одного объекта.

## Статус

Реализовано в ветке `codex/lunobot-2-266-attributes`: трёхсостояние добавлено
для Windows-флагов и Unix-разрешений, сохранение смешанных битов покрыто
регрессионными тестами. Первый CI run нашёл только lint-замечания в новом коде;
они исправлены в следующем коммите. Независимое падение Linux ARM-теста
`TestMainMenuFilePath_HasExpectedSuffix` относится к существующему flaky-тесту.
