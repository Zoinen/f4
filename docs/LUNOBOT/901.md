## Решения и инварианты

- Wayland требует, чтобы запросы с новыми объектами приходили композитору в
  порядке выделения идентификаторов. Исправление должно сохранять этот порядок
  при параллельном создании объектов из event loop и render-потока.
- Нельзя объявлять проблему окончательно решённой только по наличию fork в
  `go.mod`: upstream PR ещё не принят, а пользовательская проверка остаётся
  отдельным критерием.
- Переход на upstream допустим только после проверки содержимого и CI
  upstream PR, а также проверки f4 на актуальном Wayland-сценарии.
- Production-код в этой части не менялся; документ фиксирует состояние уже
  существующего workaround и границы следующего решения.
