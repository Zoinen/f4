## Решение и инварианты

- Документация описывает только уже опубликованный CI-контракт: Termux, Android arm64, NDK/CGO-сборка и два текущих имени артефактов.
- Универсальная инструкция обновления расположена рядом с общей таблицей загрузок; Android-раздел содержит только Android/Termux-специфичные сведения.
- `.deb` устанавливается командой `pkg install ./f4-termux-arm64.deb`; архив остаётся альтернативой для ручного запуска.
- README не обещает standalone APK, запуск вне Termux или архитектуры, которых nightly сейчас не публикует.
- Наблюдения о текущей директории и сохранении настроек из обсуждения не смешиваются с этой частью: это отдельные поведенческие задачи и требуют собственных критериев.
- Для поведенческой части отдельный PR Лунобота не нужен: автор уже объединил #908, #919 и #920, а их область и проверки изучены полностью.
- Текущий оставшийся пункт — публикация в каталоге Termux после релиза; до появления релиза не создаём фиктивную публикацию и не закрываем тикет.
- Тикет не закрывается автоматически.
