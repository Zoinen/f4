# Test coverage — console image overlay key

Codecov показывает нулевое покрытие `cmd/f4/image_console_overlay.go`.
Добавлен тест `consoleFrameKey`: неизменный кадр сохраняет ключ, а изменение
изображения, положения, crop-параметров, числа частей или общей геометрии
создаёт новый ключ.

Первый CI-прогон выявил ошибку только в самом тесте: вариант `moved` менял
координаты placement, но не заранее вычисленный `consolePiece.rect`. Тест
исправлен так, чтобы менять обе части входного кадра.

Следующий CI-прогон прошёл тесты, но build job потребовал стандартное
форматирование `gofmt`; тест приведён к многострочному виду.

Проверка выполняется GitHub CI; локальные Go-сборки и тесты не запускаются по
инструкции Лунобота.
