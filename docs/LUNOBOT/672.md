## Решения

- Сохранена текущая матрица `test` из `main`: affected-package отбор,
  перемешивание тестов, разбиение macOS/Windows на shard-ы и отдельная проверка
  `TestAllDialogs_LayoutValidation`.
- Профиль покрытия создаётся в Linux/amd64 и в обоих shard-ах каждой desktop-ОС;
  shard-ы одной ОС используют один Codecov flag, чтобы их данные объединялись.
- Загрузка выполняется только если профиль создан. Codecov остаётся
  informational и не может сделать CI красным из-за отсутствующего токена или
  ошибки загрузки.

## Инварианты

- Покрытие не меняет набор тестов, порядок проверки affected packages или
  платформенный охват матрицы.
- `-coverpkg=./...` учитывает покрытие импортируемых пакетов, а `disable_search`
  не позволяет Codecov принять `cmd/f4/lang/coverage_baseline.txt` за профиль Go.
- После первого CI shellcheck нашёл `SC2086` в намеренном разборе флагов;
  флаги исправлены через `read -r -a` и передаются как отдельные аргументы.
- Локальные сборки и тесты не выполнялись; использованы только `git diff --check`
  и GitHub Actions.
