# Issue #413 — группы сортировки

Дата среза: 09-09-2026. База ветки: `37796c36ecbddd6297f55cd31656de6f2860527`.

## Текущий статус

Базовая сортировка групп уже находится в `main`. Автор подтвердил, что она
работает, и попросил проверить объединение с правилами подсветки по модели
Far3, чтобы маски и атрибуты не приходилось задавать дважды.

В этой части `[Highlight_N]` может получить ключ `Group`: тот же matcher
используется и для цвета, и для положения файла в сортировочной группе. Старые
`[SortGroup_N]` сохраняются как совместимый формат. Добавлены проверки загрузки
общих и legacy-правил и обновлена документация `HIGHLIGHTING.md`.

В CI также исправлена изоляция добавленного ранее теста плейлиста: перед
временной подменой каталога конфигурации он теперь инициализирует
once-only-кэш, поэтому shuffled-тесты не оставляют пустой путь.

## Критерии приёмки

- правило `[Highlight_N]` с `Group` участвует в сортировке и продолжает
  использовать свои цветовые параметры;
- несколько правил с одним `Group` образуют один кластер;
- профиль со старыми `[SortGroup_N]` продолжает загружаться;
- правила без `Group` не начинают влиять на сортировку;
- обычная сортировка и режим по умолчанию не меняются.

Локальные сборки и тесты не выполняются по паспорту проекта. GitHub CI run
`34295674611` для commit `99be48565129cd78371864939cf7cba49080bc18` завершён
успешно; следующий шаг — merge PR #1019.
