# Rectangular selection must preserve rendered geometry

Alt-block selection cannot be reconstructed from text offsets alone: empty
editor rows share offsets, while native multiline inputs may wrap or add
presentation-only line breaks. Keep the mouse endpoint's visual row and cell
column as explicit state, and pass the active native wrap width to the shared
selection logic. In Qt drag tests, compute each pointer position from the live
layout after press-time reflow or scrolling; pre-press scene coordinates can be
stale even when the intended local cell is unchanged.

Cover both the visible interaction and the core extraction result: include an
empty-row copy regression, a rendered wrapped-input drag that checks the
geometry sent to Go, and a core test that copies/deletes using the supplied
wrap width.
