# Active grouping choice toggles direction

**Date:** 2026-09-22 18:49
**Files:** qt/host/qml/FilePanelView.qml, qt/host/qml/PanelRendererMenu.qml, qt/host/tests/F4QuickViewSurfaceTests.cpp
**Severity:** low

## Problem

Group by exposed a separate Reverse order row instead of showing direction on
the active criterion and reversing it on repeated activation.

## Root Cause

Choice dispatch treated every criterion activation as mode selection only, and
the active indicator was always a check mark.

## Solution

Remove the reverse row. Show an up/down arrow for the active non-Off criterion
and toggle reversal when that criterion is activated again. Preserve reversal
when switching criteria or toggling folder separation. Date grouping defaults
to newest-first, unlike ascending name/size ranks, so its arrow accounts for
that ordering. Off and folder separation retain check marks.

## Prevention

The new regression first failed on the old indicator, then passed with actual
menu clicks in both directions and checks of the emitted panel action. Menu
navigation tests derive their row count from descriptors rather than a fixed
count. Nine focused Qt test results passed, including submenu geometry/pixel
alignment, hover switching, zoom behavior, and resource-only QML imports.
The static host, embedded payload, and portable Go launcher were rebuilt.
Keep direction indicators tied to the grouping engine's actual rank semantics.
