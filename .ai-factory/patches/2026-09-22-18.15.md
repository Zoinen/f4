# Increase list-mode zoom range and scale column icons

**Date:** 2026-09-22 18:15
**Files:** qt/host/qml/GalleryPanelHostAdapter.qml; third_party/ZoinGallery/GalleryLayoutEngine.cpp; third_party/ZoinGallery/qml/{GalleryViewportController,StandaloneToolbar,GalleryEntryDelegateBase,GalleryEntryPreview}.qml; gallery layout and interaction tests
**Severity:** low

## Problem

Details and two/three-column modes stopped at density 72. Column icons remained
compact when row height grew.

## Root Cause

The range was enforced independently by native layout normalization, embedded
host controls, viewport gestures and standalone controls. Columns still used the
fixed compact preview/icon sizing rather than the shared growing Details slot.

## Solution

Raise the shared Columns/Details maximum to 216 in all four range consumers.
Reuse the pixel-snapped growing Details preview and icon geometry in Columns.
Other modes, defaults and minimum values remain unchanged.

## Prevention

The density regression failed at 200 being clamped to 72 before the change.
Updated normalization tests cover both modes and their new maximum. Extended
QML tests exercise actual icons at 216 in Details and two/three columns.
Existing Details pixel-grid and growth checks remain enabled at DPR 1.75.
Further useful coverage: persistence and restoring large densities after switching
between list modes and thumbnail modes.
