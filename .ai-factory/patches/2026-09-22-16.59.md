# Center group header text by its visible glyph bounds

## Problem and cause

Centering a Text item's implicit line height independently of the icon does not
center its visible ink. Font ascent/descent and glyph-specific whitespace left
the header text visually lower. The rendered regression at 175% measured the
count's ink center at 315.5 physical pixels versus the chevron at 312.

## Fix

Use FontMetrics.tightBoundingRect and the Text baselineOffset to center the
title and count's visible glyph bounds in the header body. Snap the resulting
position to physical pixels. The chevron geometry and noninteractive top gap
are unchanged. Metrics are bound to text/font changes, not evaluated per frame.

## Verification

The regression failed before implementation and passes afterward. It compares
rendered glyph centers against the chevron (within one physical pixel) and
retains leaf origin, unit-transform, raster-size and framebuffer checks.
Coverage includes Folders, Alpha with a descender, No data, expanded and collapsed
icons. All five DPR CTest variants passed from 100% through 200%, including 175%.
The 175% capture was inspected for title, count and icon placement.

Static host and portable launcher rebuilt, embedded payload regenerated, static
QML imports test and both repositories' diff whitespace checks passed.

## Prevention

Test visible glyph alignment as well as item geometry. More localized scripts
and user font choices are useful additional visual coverage. Failure diagnostics
include measured physical ink centers; no runtime logging is added.
