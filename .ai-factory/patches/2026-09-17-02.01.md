# Center the first native zoom with a cached viewer session

**Date:** 2026-09-17 02:01
**Files:** qt/host/qml/ShellSurfaceHost.qml, qt/host/tests/F4QuickViewSurfaceTests.cpp, qt/host/tests/TestGalleryPanel.qml
**Severity:** medium

## Problem

Opening a cached image and pressing `*` once displayed the correctly sized 100%
image above and left of center. Pressing `*` again centered it correctly.

## Root Cause

The viewer Loader assigned its session before its device-pixel ratio. Assigning
a cached session synchronously installed image metadata using the default DPR
of 1. The subsequent DPR binding did not reapply an unchanged cached source.
The first native-zoom target therefore used the wrong logical image dimensions.
When the native tier arrived it corrected the dimensions, but retained the
already calculated zoom offsets.

The real-host regression reproduced a physical center error of
(-523.75, -287.75) pixels with a 1396x768 image at DPR 1.75. Its cached logical
size was 1396x768 rather than 797.714x438.857. This displacement matches half the
difference between the incorrectly scaled and native image extents.

## Solution

Bind the actual screen DPR before attaching the image session in the existing
Loader. Both cached and asynchronously decoded images then use the same logical
size from the beginning. Zoom interpolation, filtering and color management do
not need changes.

The integration regression warms a real GallerySession fit image, opens the real
GalleryViewerHost through ShellSurfaceHost, and sends exactly one `*` key press.
It checks the native-tier handoff, stable logical size, actual image dimensions,
center, whole physical-pixel leaf origin, and identity scene transform at 175%.
The fixed center error is (0.25, 0.25) physical pixels, the expected neighboring
pixel chosen when the mathematical center lies between pixels.

The first-zoom regression, viewer chrome/transition coverage, workspace text
pixel-grid check, embedded-only QML import check, Windows dependency audit, and
embedded-host extraction tests pass. Tests were automated and nonvisual.

## Prevention

- Supply coordinate-system inputs before attaching data that can synchronously
  publish geometry during a QML property-change handler.
- Exercise warm-cache startup through the actual host Loader. A cold decode
  can finish after all bindings are set and hide an initialization-order bug.
- Assert the first user action; repeating it can recalculate stale geometry and
  conceal the defect.
- Record both logical source sizes and physical scene-space errors at a
  fractional DPR to distinguish stale geometry from subpixel rendering errors.
