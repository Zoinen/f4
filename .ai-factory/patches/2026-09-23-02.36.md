# Align Qt menu, sticky group header, and drop target visuals

## Problem

The Thumbnails checkmark sat lower than the matching renderer checkmark. Sticky
group headers stayed opaque through their lower edge when hovered. Drop-target
outlines ignored the Gallery's newly internalized horizontal content padding.

## Root cause

The Thumbnails row gave its leading Row the full parent height, unlike the
renderer rows' implicit-height layout. The sticky header's hover rectangle
painted an opaque fill over the base gradient. Drop outlines used file geometry
without the layout padding offset (or horizontal `contentY` in Columns).

## Fix

Reuse the renderer row's vertically centered check slot. Keep the separator at
the viewport top edge when sticky and fade both the header and hover background
to transparent. Offset and clip file drop outlines by the layout's horizontal
padding, accounting for horizontal scrolling in Columns.

## Prevention

At DPR 1.75, compare actual menu leaf centers, compare visible sticky-header
pixels against a capture with the header hidden (for base and hover states),
and compare drop-outline coordinates with native file geometry in every
presentation mode.

## Verification

The focused Thumbnails menu test, drop-outline test, sticky-header render test,
and static-QML-import test passed. Rebuilt the static Qt host, regenerated its
embedded payload, rebuilt the worktree Go launcher, and verified that the
embedded host opened a window from a fresh extraction cache. `git diff --check`
passed for both repositories.
