# Preserve GUI shutdown evidence

**Date:** 2026-11-13 00:30
**Files:** internal/plughost/extui.go, qt/host/src/QtShellController.cpp, qt/host/src/main.cpp
**Severity:** medium

## Problem

The Qt window disappeared without a macOS crash report or enough information in the F4 session log to distinguish an application exit from an external termination.

## Root Cause

The underlying termination was unconfirmed. The diagnostic gap was that the core discarded the host's wait status, cancelled the host immediately after sending quit, and logged IPC disconnects only in debug mode.

## Solution

Log the process IDs, quit messages, disconnection, Qt event-loop exit, and host wait result in the session's stderr log. Give the host a short grace period after the event loop returns, and record when cleanup falls back to cancellation.

## Prevention

Check both a clean quit and a host terminated by a signal. For a macOS development launch from Documents, use a detached watcher to record the core's exit code or signal. A launch agent in the user domain was denied access to the launcher in Documents.
