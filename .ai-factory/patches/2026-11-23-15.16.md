# Present PDFs at viewport resolution on file switches

**Date** 2026-11-23 15:16

**Files** `GalleryPageController.cpp`, `GalleryPagePresentation.qml`, `F4QuickViewSurfaceTests.cpp`

**Severity** medium

## Problem

Switching between PDFs briefly showed a soft page before sharpening. The regression at 175% captured a 90×128 panel thumbnail in the viewer while the viewport render was pending.

## Root Cause

Fit mode applied the panel thumbnail as a temporary document frame. Manual zoom published a fit-sized raster before requesting the visible detail. The page worker also discarded its raster cache when changing documents.

## Solution

Prepare adjacent local PDFs at the viewer's physical dimensions and keep viewport frames in a bounded cache across file changes. Keep the outgoing frame until the target raster is ready. At manual zoom, prepare and commit the visible crop with the target page.

## Prevention

Pause the renderer to verify an uncached switch retains the original pixels and a prepared neighbor and revisits still display. At 175%, compare the first displayed raster with the viewport dimensions and verify the visible crop is ready on the first frame at manual zoom.
