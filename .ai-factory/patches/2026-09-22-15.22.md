# Preserve folder-preview authority through full scene projection

**Date:** 2026-09-22 15:22
**Files:** internal/nativeui/scene.go; internal/nativeui/directory_preview_projection_test.go; qt/host/tests/F4GalleryBridgeTests.cpp; qt/host/README.md
**Severity:** high

## Problem

Folder thumbnails disappeared after selecting Group by Extension. Previous
fixes protected paged directory authorities and temporary layout demand, but
did not cover the full-scene adapter used after a catalog revision changes.

## Root Cause

The incremental scene path rejects a changed catalog revision and falls back
to full projection. `appEntryFromLegacy` copied image `source` but omitted
`directorySource`. Thus a folder which had acquired a preview through paged
rows lost its enumeration authority when the replacement scene arrived.
Gallery correctly treats missing authority as removal and retires its preview.

## Solution

Copy the complete directory descriptor (resource ID, source key, version) into
the typed file entry during full projection. Preserve the distinction between
directory enumeration authority and image byte authority. Add opt-in
`[FIX:directory-preview-projection]` diagnostics using the existing debug log.

The new full-scene regression failed before the fix for both ungrouped and
Extension catalogs, proving the descriptor disappeared. It passes afterward.
The Qt bridge regression also replaces a populated folder catalog with an
Extension group and verifies the same preview model survives without another
enumeration.

## Verification

- Full `GOWORK=off CGO_ENABLED=0 go test ./...` passed.
- Rebuilt static host/test targets; Qt bridge regression passed.
- Static `qmlImportsWithoutInstalledQt` passed.
- Regenerated embedded payload and rebuilt the worktree executable.
- Direct `--gui=qt` launch from a fresh extraction cache created a responsive
  `f4 [zoin]` window. The actual menu transition in `P:\[Year 2026]` was not
  visually replayed; regression coverage exercises projection and Qt retention.

## Prevention

Test both paged responses and full-scene projection whenever adding a file-row
descriptor. A renderer-only reorder test cannot detect data discarded by Go
before transport. Further useful coverage is an end-to-end recorded-protocol
test of repeated grouping changes after a paged initial directory load.
