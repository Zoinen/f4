# Gallery settings controls and background usage polling

**Date:** 2026-09-16 02:21
**Files:** qt/host/qml/GallerySettingsPage.qml; qt/host/tests/F4QuickViewSurfaceTests.cpp; third_party/ZoinGallery/include/ZoinGallery/GalleryPreferences.h; third_party/ZoinGallery/src/embed/GalleryPreferences.cpp; third_party/ZoinGallery/tests/GallerySessionTest.cpp
**Severity:** medium

## Problem

The clear-cache action repeatedly changed its label and enabled state while the
settings page was idle. Cache modes used segmented buttons; booleans used checked
buttons; hand-built text inputs did not match the other settings pages.

## Root Cause

The three-second usage timer used the same busy flag and budget-maintenance path
as explicit Apply/Clear operations. The UI interpreted each read-only poll as a
user operation. The page also duplicated controls instead of using F4's shared
settings components.

## Solution

Use F4TextField, F4ComboBox, F4CheckBox and F4Button. Give combo options named text
roles compatible with the shared popup. Poll usage independently of maintenance,
with at most one outstanding poll. An explicit operation may queue behind that
poll on the existing single cache worker. Keep action labels stable and announce
clear completion only after the worker finishes. Opt-in media trace events carry
the [FIX:cache-usage-refresh] marker.

## Regression checks

- Before the fix, the UI test observed "Updating cache…" instead of "Clear image
  and folder caches", and the backend test observed busy during a usage poll.
- The same checks now pass. Apply/Clear can run after a pending poll; completion
  is reported after cleanup. Backend tests use an isolated temporary cache root.
- Both dropdowns render all three option labels. Keyboard selection, checkbox
  toggling and numeric input update the draft; a usage update preserves edits.
- Actual text and raster leaves, including open dropdowns, pass scene-origin and
  identity-transform checks at DPR 1.75. The rendered page and decoder list were
  captured and inspected. Static-QML, GallerySession, Windows import and embedded
  payload tests passed.

## Prevention

Reuse the shared settings controls before introducing local replacements.
Separate passive telemetry from action state. Exercise popups and unsaved edits
during background updates, not only a settled initial screenshot. Keep fractional
DPR coverage on the actual control leaves.
