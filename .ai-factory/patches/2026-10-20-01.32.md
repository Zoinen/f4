# Preserve early Settings scrolling through layout and focus acknowledgement

**Date:** 2026-10-20 01:32 Europe/Moscow
**Severity:** medium
**Files:** qt/host/qml/SemanticGroupViewport.qml;
qt/host/tests/F4OperationsQueueTests.cpp;
internal/settings/center_semantic.go, center_semantic_test.go

## Problem

Scrolling immediately after opening a File Group editor could return to the top.
The existing retained-scene test passed because it refreshed only preview colours,
without changing layout or replaying focus acknowledgement.

## Root Cause

Maximum-scroll changes unconditionally restored the last Go scroll position.
During initial asynchronous layout that position could still be zero while native
touchpad scrolling had moved the viewport. Independently, native text-input focus
gain emitted control.focus for an already focused upper field; the Go viewport
unconditionally revealed that unchanged field after accepting the action.

## Solution

Geometry-only changes clamp the current pixel offset rather than reapplying the
semantic offset. Initial restoration and explicit remote-scroll changes retain
their synchronization path. Same-target focus acknowledgements are idempotent for
viewport scrolling; real focus transitions still reveal the target. Event-driven
VTUI_DEBUG logging uses [FIX:settings-scroll]. No profile data is modified.

## Verification

Before the QML fix, late-layout regression changed contentY from 180 to zero.
Before the Go fix, same-target acknowledgement changed scroll from 20 to 1.
The same checks pass after their respective fixes. Regression coverage includes
changed-target reveal and existing retained preview, scroll and resize checks.

## Prevention

Test the first-open sequence with layout changes after local input and before
the semantic acknowledgement, not only settled identical scene refreshes.
Distinguish native focus acknowledgement from deliberate navigation. Additional
useful coverage is a physical trackpad gesture immediately after opening, with
application deactivation/reactivation and Low Power Mode.
