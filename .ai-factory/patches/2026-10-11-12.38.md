# Native dialog separators and shared vertical gallery padding

## Root cause

`vtui.Separator` had no native semantic projection and appeared as an empty
generic widget. Alt+F7 also embeds its live result count in a private separator
whose caption is not a child control. QML therefore omitted both section lines
and the result-count caption.

Grid, Icons and Masonry used unrelated vertical padding constants. Changing
only the delegate would leave native row geometry, caption reservations and
Masonry aspect ratios inconsistent.

## Fix

- Project standard separators in nativeui and export the private Find File
  result separator through its own semantic provider.
- Use one reusable QML separator delegate with a centered optional caption,
  gaps beside its text, visibility propagation and one-physical-pixel rules.
- Add Qt-owned `galleryCellVerticalPadding` alongside horizontal padding;
  default 4, clamped to 0–32, saved and restored. Reuse one titlebar control for
  the separate Horizontal and Vertical live sliders.
- Pass vertical padding into the shared layout request. Reserve top/bottom
  insets plus caption height in fixed modes; include separate horizontal and
  vertical spacing in justified Masonry. Folder collages retain their own
  internal spacing. Details/Columns keep independent column padding.
- Delegates use the committed native inset when minimum zoom clamps a large
  requested margin, so caption/folder spacing cannot diverge from the preview.
- Vertical changes reuse existing Icons caption measurements. Floor available
  caption height instead of rounding up beyond the cell, and snap actual image
  leaves as well as wrappers at fractional DPR.

## Regression evidence

- Go tests first failed for the missing standard and private semantic
  separators; post-fix `CGO_ENABLED=0 go test ./...` passed.
- The titlebar regression first failed for missing vertical padding. Both live
  axes, persistence, defaults, clamping and independent compact-mode padding
  pass.
- `F4DialogSeparatorsPixelGridTest` and `F4GalleryCellPaddingPixelGridTest` pass
  with offscreen DPR 1.75, checking actual text/rule/slider leaves, unit
  transforms and separator pixels.
- The layout engine suite passes (23 checks). Rendered Grid/Icons/Masonry file
  and folder tests cover horizontal/vertical padding combinations, caption and
  preview bounds, aspect ratios, unchanged caption measurement count and actual
  image/text/frame leaves at DPR 1.75. Related variable-row, two-line Grid and
  folder-preview reuse regressions also pass (12 checks).
- Canonical worktree Go+Qt build passed with video and FFmpeg enabled; nine
  related CTest suites passed, including semantic dialogs, both architecture
  gates, bridge/pointer and resize-retention regressions.
- Restarted the actual worktree Go and Qt processes. Alt+F7 showed section
  lines immediately and a real completed search showed `Found: 6 | Scanned: 68`
  centered between the result-separator rules. Live dragging changed both
  panels at 0, 16 and 32 px; Grid/Icons/Masonry and folder previews were checked.
  Restored vertical padding to 4 and verified it in `gui_theme.ini`.

## Prevention

Custom vtui controls that paint text outside their child tree need an explicit
semantic provider. Native and QML layout must share padding and caption
reservations. Always test actual rendered leaves at fractional DPR: a snapped
wrapper alone does not guarantee a sharp, contained image or caption.
