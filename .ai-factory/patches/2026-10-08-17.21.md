# Verify Conan packages across all recipe revisions

**Date:** 2026-10-08 17:21 MSK
**Files:** `ci/upload-conan-packages.py`, `ci/test_portable_conan_upload.py`
**Severity:** medium

## Problem

The Linux release verifier reported an existing Qt package revision as missing
from Artifactory, even though Conan's upload check confirmed that exact
revision was already present.

## Root Cause

The remote listing pattern selected all package revisions only for the latest
recipe revision. Artifactory can contain the exact required package under an
older recipe revision, which the query omitted.

## Solution

List all recipe revisions and all package revisions when verifying required
packages on Artifactory. Add a regression asserting the complete Conan query
pattern.

## Prevention

- When validating immutable Conan references, wildcard each revision dimension
  that must be searched instead of relying on the command's default latest
  recipe revision.
- Keep a command-level regression for the exact remote listing pattern.
