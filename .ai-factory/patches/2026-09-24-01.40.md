# Preserve embedding insets in Details layout

## Problem and cause

Details discarded the host's horizontal inset by setting layout padding to
zero. That exception originally removed Gallery's own tile spacing, but also
removed the external spacing after it moved inside the viewport.

## Fix

Always retain the embedding inset; add Gallery's six-pixel tile padding only
for other layouts. Keep the viewport and group headers full-width. Existing
opt-in content-inset tracing reports the corrected values.

## Verification and prevention

The existing native pointer/drop test now checks both insets while switching
through all five layouts. It passes with the offscreen backend at DPR 1.75,
including drop alignment and scrollbar drag exclusion. The static import
check passes. Rebuilt the portable application and verified window creation
from a fresh cache whose host hash matches the newly built Qt executable.

Keep embedding insets separate from presentation-specific tile spacing.
