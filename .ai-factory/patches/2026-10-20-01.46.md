# Folder icon colour belongs to the file colour theme

**Date:** 2026-10-20 01:46
**Files:** third_party/ZoinGallery/qml/GalleryEntryDelegateBase.qml, qt/host/qml/HostThemePalette.qml, qt/host/qml/F4HostWindow.qml, internal/filegroups/colors.default.ini, internal/filegroups/migrate_folders.go, internal/filegroups/store.go
**Severity:** medium

## Problem

Folder icons stayed blue regardless of their resolved file-group colour theme.

## Root Cause

The shared delegate gave folders a separate application UI colour before consulting
the semantic foreground. Moving defaults into an INI alone could not fix this:
existing complete Current theme snapshots still stored the former white/grey values.

## Solution

Resolved group foreground now wins for folders, including the parent row, in all
layouts. The separate Folder Icon UI setting is removed; standalone fallback is
neutral. Current stores the former blue as data. Exact old four-state entries
migrate in memory; custom states and other themes remain untouched. Apply uses
the existing conflict check and atomic publication with a dedicated backup.
Migration diagnostics use `[FIX:file-group-folder-colors]` through DebugLog.

The corrected typed-snapshot Qt regression failed before the delegate fix and
passed afterwards for six modes and both folder types. Go filegroups/theme/
settings/nativeui tests and vet passed with CGO disabled. The broader offscreen
175% QuickView suite exposed unrelated workspace-tab/viewer assertions; a control
run with today's QML changes temporarily absent reproduced the same failures.
That broader suite is not claimed green. Targeted colour, icon-fit and aspect
tests passed on the final build; no running editor or user profile was changed.

## Prevention

Test semantic style propagation through the actual typed highlightStyle snapshot,
not invented flat roles. Exercise ordinary, cursor and marked states across all
layouts at fractional DPR. Test migration without opening a real user profile,
including custom values, failed saves and external changes.
