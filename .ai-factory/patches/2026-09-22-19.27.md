# Keep gallery scrollbar thumbs visible in large directories

## Root cause

The custom scrollbar had no explicit usable minimum thumb size. With 29,291
entries the painted handle measured only eight logical pixels, a dot rather
than a recognizable scrollbar. Existing tests checked the control's visible
flag and proportional range but not its painted handle's extent.

## Fix

Set minimumSize from a 24-pixel visual thumb extent divided by the track extent,
bounded to one. The four-pixel margins leave a minimum 16-pixel painted handle.
Keep the logical size and position proportional so navigation still reaches
both endpoints. This applies to horizontal and vertical gallery scrollbars.

## Verification

The sparse Details regression failed with handle height 8 before the change
and passed with height 16 afterward. Sparse endpoint/Home behavior, vertical
dragging, horizontal placement, actual leaf origins and unit transforms at
DPR 1.75, and rendered capture passed. Static QML imports and splitter checks
also passed. Rebuilt the static host, embedded payload, and portable launcher.

## Prevention

Visibility flags do not prove usability: test the painted thumb extent and
rendered appearance with a high-cardinality catalog, not just a short list.
