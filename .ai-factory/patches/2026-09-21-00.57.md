# NetFox root path title

**Date:** 2026-09-21 00:57
**Files:** `plugins/netfox/vfs.go`, `plugins/netfox/netfox_paths_test.go`
**Severity:** low

## Problem

The NetFox manager root was rendered as the transport URI `net://` in the
panel path control. The expected user-facing label is `Network`, while child
connection paths must remain qualified URIs.

## Root Cause

The root `NetFoxVFS` did not implement `vfs.PanelTitleProvider`. The common
panel title code therefore fell back to `GetPath()` and displayed the
canonical URI directly.

## Solution

Added a root-only `PanelTitle` implementation returning `Network` for
`net://`, while leaving all non-root paths unchanged. Added a debug marker
`[FIX:netfox-path]` and a regression test for the root title.

## Prevention

- Keep canonical VFS paths separate from user-facing panel titles.
- Add title assertions whenever a virtual filesystem introduces a new root
  URI.
