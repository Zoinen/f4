# Conan verification omitted package revisions

**Date:** 2026-10-08 16:17 MSK
**Files:** `ci/upload-conan-packages.py`, `ci/test_portable_conan_upload.py`
**Severity:** medium

## Problem

Both Linux portable Qt release jobs built and audited their binaries, but the
required Artifactory gate reported that the cached Qt, PulseAudio, FFmpeg, and
libffi packages were missing for the target architecture.

## Root Cause

The verifier parsed package revision IDs from Conan's JSON, but its default
`conan list` pattern (`*/*:*`) listed package IDs without requesting their
package revisions. As a result, the expected-revisions set was empty even
though the installed packages and their settings were present.

## Solution

Request all package revisions in the default cache listing with `*/*:*#*`.
Keep the architecture and exact package-revision checks unchanged. Add a unit
regression that verifies the query requests package revisions.

## Prevention

- Match Conan reference patterns to the metadata the verifier consumes: package
  IDs and package revisions are distinct query dimensions.
- Test command arguments as well as JSON parsing so a future query change cannot
  silently remove fields required by the verification gate.
