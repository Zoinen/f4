## PulseAudio finder

The Linux Qt build already requested Qt Multimedia, FFmpeg and PulseAudio, and
the Conan graph contained `pulseaudio::pulse`. Qt's `FindWrapPulseAudio.cmake`
instead required the legacy `PULSEAUDIO_LIBRARY` and
`PULSEAUDIO_INCLUDE_DIR` variables, so Qt correctly rejected the forced-on
audio feature. The Linux recipe patch now adapts the finder to wrap and link
Conan's `pulseaudio::pulse` target, while preserving Qt's original system
finder as a fallback. Audio is reported found only when the Conan target
exists.

The configure-only CMake regression fixture confirms the original finder fails
with a Conan-style target package and the patched finder succeeds and links
that target.

## Linux release lane

The explicit Qt feature-release input now builds only the Linux amd64 and
arm64 single-file artifacts. It no longer waits for unrelated Windows/macOS
Qt builds, so a Windows runner regression cannot block the requested Linux
release. Both Linux builds use the normal glibc 2.27 contract and require
Artifactory verification of Qt, PulseAudio, FFmpeg, and libffi packages before
the two archives are published.

## ARM64 glibc 2.27 baseline

The failed ARM64 build consumed a cached `libffi/3.4.8` archive whose undefined
symbols included `__isoc23_sscanf`, which the Ubuntu 18.04 / glibc 2.27 linker
cannot provide. The existing compatibility guard scanned four video archives
but omitted `libffi.a`. A small tested scanner now covers `libffi` alongside
the other static archives and selects only absent or incompatible packages
for a baseline rebuild. The Conan publication gate also requires the rebuilt
`libffi/3.4.8` package to be readable from Artifactory.

## Exact Conan binary publication

The previous publication gate compared only the recipe revision and package
ID. That could accept an older package revision (PREV) for the same
configuration, even when the newly rebuilt binary had not been uploaded. The
gate now compares exact PREVs and queries Artifactory for all package
revisions; a regression test proves an old same-ID binary is rejected.
