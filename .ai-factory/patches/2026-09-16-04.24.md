# Preserve Masonry paging through unchanged cached metadata

**Date:** 2026-09-16 04:24
**Files:** third_party/ZoinGallery/GalleryGeometryIndex.{cpp,h}; MasonryLayoutGeometry.cpp; qml/GalleryNavigationController.qml; qml/GalleryPanelMotion.qml; tests/MasonryLayoutModesTest.cpp; qt/host/qml/GalleryPanelHostAdapter.qml; qt/host/tests/F4GalleryBridgeTests.cpp; qt/host/CMakeLists.txt; qt/host/README.md
**Severity:** high

## Problem

PageDown after entering an image folder moved only part of a page; alternating
PageUp/PageDown could keep the user around the same first rows. The report named
`P:\[Year 2026]\[2026] 4A`. Live keyboard/window automation was stopped at the
user's request; subsequent diagnosis and verification used isolated offscreen tests.

## Root Cause

Every Masonry rewrap cleared and rebuilt the row index, then published a new
layout revision, even if every cell retained exactly the same geometry. Repeated
metadata notifications from newly visible images therefore invalidated the Page
animation, stopped it halfway, and discarded its reversible history. Warm metadata
did not prevent this: publication of already cached dimensions was sufficient.

The first simple navigation fixture passed before the fix. Adding the actual
sparse-to-dense handoff and 355 cached image records still passed until an unchanged
metadata publication during the page animation was included. That regression then
failed before implementation. The real F4 host fixture independently reproduced
PageDown planning 792 logical pixels but stopping at 403.161 pixels (352.151 in the
instrumented run) in a 900-pixel viewport, before any cursor acknowledgement.

## Solution

Retain compact cell records in GalleryGeometryIndex. Compare all index, row and
rectangle fields before rebuilding; publish a layout revision only if those
geometries change. Preserve page animation and history across unchanged metadata.
Keep existing invalidation for actual geometry changes and model replacement.

Expose planned page targets, geometry invalidation and scroll animation state
under the existing opt-in navigation trace. Enable passive QML trace forwarding
without requiring the automatic benchmark runner. Register the existing static Qt
platform/image plugins for GalleryLayoutEngineTests, which previously blocked on
platform discovery before reaching QtTest.

## Prevention

Test a completed page displacement and its reciprocal return, not merely the
selected index or planned target. Include asynchronous publication of unchanged
metadata while scrolling, plus the host acknowledgement path. Geometry revisions
must describe a change in geometry, not an invocation of the layout algorithm.
