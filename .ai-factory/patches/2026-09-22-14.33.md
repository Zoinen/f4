# Fix: panel content inset belongs to the Gallery surface

## Problem

`FilePanelView` placed the Gallery loader eight logical pixels inside the
panel on both horizontal sides. The margin was therefore outside
`GalleryPanelHost` and its masonry layout: group separators could not reach the
panel edges, and pointer events in that strip missed the Gallery hit-test
surface.

## Root cause

Panel chrome spacing was represented as loader margins instead of renderer
padding. The Gallery viewport also represented its six-pixel tile inset as
layout anchor margins, so the renderer could not own the complete interactive
panel rectangle.

## Fix

- Make the Gallery loader fill the panel horizontally.
- Pass `panelContentSpacing` through `GalleryPanelHost` and `GalleryPanel` as
  `contentHorizontalInset`.
- Replace horizontal viewport anchor margins with layout padding, preserving
  the existing tile geometry while allowing separators and pointer routing to
  use the full panel surface.
- Reapply presentation state when the inset changes without causing a catalog
  replacement or thumbnail regeneration.
- Keep the diagnostic path opt-in and tag it with
  `[FIX:panel-content-inset]`.

## Regression coverage

- `F4QuickViewSurfaceTests::galleryContentInsetBelongsToRendererPanel`
  failed before the fix because the production loader had a non-zero X offset;
  it now verifies a full-width loader and renderer-owned inset.
- `verticalScrollBarDoesNotChangeViewportWidth` verifies zero external layout
  margins and equivalent internal padding.
- `groupedLayoutsRenderHeadersAndSkipCollapsedRows` verifies separators span
  the complete panel width.
- `groupedPanelCapturesPointerForGroupedEntries` clicks a grouped header near
  the panel edge after applying the inset.

## Prevention

Keep embedding-panel spacing inside the renderer surface. Do not add
horizontal loader margins around interactive Gallery content; expose a
renderer inset/padding property instead so separators, overlays, and hit
testing share the same full-width coordinate space.
