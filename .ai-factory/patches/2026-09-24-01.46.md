# Preserve icon names when retargeting Lucide provider requests

## Problem

Folder and parent-directory icons became generic file icons after enabling
size-dependent Lucide strokes.

## Root Cause

Gallery extracted the last component of image-provider URLs as a semantic
icon name. The host encodes that component with unpadded URL-safe Base64.
The new stroke-width path sent the encoded token back to the host as a name,
which failed its icon allowlist and selected the generic file fallback.

## Solution

Decode and validate the provider route before returning its semantic key.
Static resource paths keep their existing handling. Extend the existing
resolver test to assert exact names for file, folder, folder-up and file-image.

## Prevention

Test semantic identity through provider URL round trips, not merely whether
the extracted string is nonempty. Keep URL encoding separate from icon names.
