# Native help and standalone menu titles

## Symptoms and causes

- F1 pushed `HelpView` in Go, but its semantic node was `kind: fallback`.
  The native scene adapter had no help content to publish, leaving the panels
  visible underneath an invisible active help frame.
- F2's user menu already supplied its title (including nested-menu breadcrumbs).
  `SemanticMenuPopup` rendered only items and a bottom hint, so an empty user
  menu appeared as a small hint-only strip.

## Changes

- Export help as an owner-declared `dialog` / `layout: help`, retaining Go topic,
  history, selected-link and scroll ownership. Publish only visible formatted
  rows, including sticky headings. Share the HLF span parser with console
  rendering instead of parsing HLF again in QML.
- Route native link, back, close, wheel, scrollbar and viewport-capacity actions
  to HelpView. Reject stale-topic link activation. Restore the title on Back.
- Add a native help overlay with clickable links and scroll controls.
- Show a title for standalone titled menus, reserving header height and keeping
  dropdowns, menu-bar popups and anchored child menus unchanged.
- Opt-in `F4_HELP_TRACE` logs handled help actions and viewport state.

## Regression coverage

The new Go help tests first failed because the exported node was unsupported.
The QML help regression first failed because `semanticHelpDialog` did not exist.
Coverage includes native scene projection, bounded/sticky help rows, navigation,
invalid actions, empty and populated menu titles, menu action routing, and title
suppression for attached menus. UI tests inspect actual text leaves' scene-space
origins and unit transforms at DPR 1.75 and support rendered captures.
An extended geometry check measured the new help title at 949 × 29.75 physical
pixels; rounding native text extents upward fixes that fractional height. The
help scrollbar reuses the existing physically aligned F4ScrollBar component.
A trackpad regression also measured 40 rows for forty one-pixel events versus
2 rows for the equivalent combined event. Retaining fractional wheel remainder
keeps these paths equivalent instead of rounding every event up to a row.

## Lesson

A working console frame is not evidence of a working native surface: verify both
the semantic projection and its QML consumer. Keep formatted-document semantics
in the owner, and test empty popups as well as populated ones.
