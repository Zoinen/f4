# Match Group by submenu to the View dropdown

## Cause

The child popup lacked the parent's custom background. Its right-side placement
added the row width twice, while left-side placement used the row's right edge
instead of the parent menu's left edge. Keyboard handlers were attached to Popup,
which is not an Item and cannot receive the Keys attached property.

## Fix

- Share the parent's background color, radius, border and row/check/icon styling.
- Position against the parent's outer edges in overlay coordinates, flip left
  when required, align the first row with Group by and clamp to window bounds.
- Keep both popups in the same overlay, with themed scrolling for short windows.
- Handle keys on focusable content; Left/Escape return to the parent and keyboard
  selection scrolls into view. Hovering another parent choice closes the submenu.
- Pixel-align actual submenu text, check/icon leaves and separators through
  ancestor movement and scrolling.
- Close on panel identity/path changes, not every ordinary state publication.

## Verification

The regression initially failed on the background mismatch (#000000 vs #222c38).
It then caught a half-pixel icon origin (1069.5 physical pixels), corrected with
reactive scene-space translation. The final test checks both opening directions,
window bounds, leaf origins/unit transforms, rendered capture, short-window
keyboard scrolling, Left/Escape and directory-change closure.

Runs with QT_SCALE_FACTOR 1, 1.75 and 2 passed. Rendered output was inspected.
Renderer ordering, zoom controls and static QML imports passed. Rebuilt the static
host, regenerated its embedded payload and rebuilt the CGO-disabled worktree app.
git diff --check passed. No new runtime logging, commit or push.

## Prevention

Test popup placement relative to the parent edges, not just screen bounds.
Check both theme properties and actual rendered leaves; inherited popup defaults
and wrapper-only pixel checks are insufficient. Further coverage can exercise
hover traversal with a native pointer across monitors of differing DPR.
