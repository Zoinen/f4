# Profile and remove Settings QML update amplification

**Date:** 2026-09-11 02:03
**Files:** qt/host/src/SemanticChildrenModel.*, qt/host/src/ScenePixelAlignment.*,
qt/host/qml/GenericDialog.qml, qt/host/qml/SemanticWidgetDelegate.qml,
qt/host/qml/SemanticGroupViewport.qml, qt/host/qml/HostPresentationUtilities.qml,
qt/host/qml/HostPixelAlignedImage.qml, internal/gui/font_catalog*.go
**Severity:** high

## Problem

Opening, help hover, page selection and resizing Settings stalled the Qt UI.

## Root cause

Whole QVariantList replacements made Repeaters destroy and recreate every control
when only help or geometry changed. Each delegate also received the complete
sibling list, multiplying conversion of large font/encoding arrays. JS pixel
correction bindings repeatedly invalidated through the ancestor hierarchy.
Separately, Go font choice mapping repeatedly cleaned paths in quadratic scans.

## Solution

Keep one live QAbstractListModel per semantic node, reconcile children by kind/ID,
and notify only changed rows/roles. Project the associated inline label rather
than all siblings. Retain bound nested loaders. Correct scene-space translations
once after layout, in ancestor order, before scene synchronization. Use per-call
normalized font sets with platform path equality; no cached catalogs or dialogs.

Real Settings replay at DPR 1.75: opening 279 -> 61 ms, hover 175–179 -> 19–24 ms,
category changes 184–270 -> 38–60 ms, native resize 156–157 -> 12–22 ms, semantic
resize 403–406 -> 40–49 ms. Frame times include image readback. Go Open/export
separately fell from 25.8 to 9.0 ms; do not add them as end-to-end timings.

## Prevention

- Export real owner scenes and separate owner CPU, serialization, Qt updates and
  rendered-frame cost. Keep QML profiler overhead out of latency comparisons.
- Assert all native control identities survive unrelated help updates. A baseline
  failed on the disabled TextInput; 204/204 controls were recreated per hover.
- Use QAbstractItemModelTester and check precise changed roles/persistent indexes.
- Test actual native text/icon leaves through complete ancestor transforms at
  DPR 1.75 after resize and scroll. A checkmark at physical y=736.25 caught an
  old icon correction path; route raster leaves through the same final pass.
- Register new production QML types declaratively in qt6_add_qml_module. Manual
  early registration in the same URI suppressed generated VtuiGridItem loading.
  The compiled-host connection smoke fails on the saved broken host and passes
  after the fix; fixture-only tests cannot cover this registration distinction.
- Repackage and start the embedded host before replacing the working worktree app.
