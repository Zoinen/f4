# Immediate native handoff below Fit

## Problem

When the viewer was manually zoomed below its Fit scale, switching images first
showed a blurry base tier and only then replaced it with the native image. Image
switches at Fit did not show the same transition.

## Root cause

`ViewerSourceController.applyNativeTier()` always deferred the full native
source by the animation duration. Above Fit, a native-quality viewport crop
bridges that delay. Below Fit, the scaled image leaves margins in the viewport,
so no crop can cover it; the controller cleared the crop and still waited 150
milliseconds before assigning the already decoded native source. During that
gap, only the lower-resolution base tier was available to the resampling shader.

## Solution

When a native crop cannot cover the viewport, assign the decoded native source
immediately and return. Keep the existing crop-plus-delay handoff for zoomed and
panned states where a native crop exists, preserving their transition behavior.

No color-profile code changed.
