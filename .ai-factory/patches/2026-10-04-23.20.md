# Open remote videos locally and honor remote shell integration

**Date:** 2026-10-04 23:20 Europe/Moscow
**Files:** internal/app/actions.go, internal/app/remote_file_execution_test.go, internal/app/qt_document_loading_test.go, internal/panel/frame.go, internal/panel/frame_progress.go, internal/panel/frame_remoteopen.go, internal/panel/frame_remoteopen_test.go, docs/TERMINAL.md
**Severity:** high

## Problem

Enter on IMG_20260527_185727.mp4 in a Windows remote HC panel printed a
POSIX-style command and appeared to hang. Ctrl+C did not interrupt it. The user
expects the video to open on the computer displaying f4.

## Root Cause

Windows FISH+ synthesizes 0755 permissions for ordinary writable files, so the
client classified a movie as executable. Enter bypassed PtyShellIntegration,
sent a Bash command group to cmd.exe and muted output until an OSC C marker
from that group. Cmd cannot execute the group, and its errors remained muted.
The remote interrupt snapshot also declined to route Ctrl+C with panels hidden,
allowing global shortcuts to consume the key. Generic progress dialogs did not
handle Ctrl+C cancellation.

## Solution

Remote videos take precedence over executable-bit detection. Download a private
local snapshot with the original filename and extension, then launch the local
desktop association. Cancellation removes partial snapshots; successful files
remain in the system temporary directory because desktop launchers can exit
before the player opens the file. Changes to that copy are not uploaded.

Remote executable activation honors the peer's formatter and command dialect,
uses prompt-driven completion on Windows and keeps output visible. POSIX
executable activation retains managed OSC C/D markers; a separate regression
caught and prevented losing them while adopting the Windows formatter.
Ctrl+C routes to the
existing remote PTY with either panels or terminal visible. Progress dialogs
route Ctrl+C through the existing cancellation callback.

## Verification

Before implementation, regressions reproduced the Bash wire command, muted
output, POSIX history and missing terminal-visible remote interrupt. The remote
movie regression timed out without a local launch. The download Ctrl+C regression
failed before adding the progress handler.

After implementation, targeted remote/media/download tests, related execution
and shell tests, architecture checks and embedded Qt payload checks pass. The
existing progress-theme test checks the actual presented frame through its
frame/container contract, retaining all theme and control rendering assertions
while allowing the cancellation wrapper.
The
Go launcher builds with CGO_ENABLED=0 and the existing embedded static Qt host.
No native Qt source or payload changes were necessary. Live HC connectivity and
playback were not verified; fixtures prove client routing, downloaded bytes,
completion, cancellation and cleanup.

## Prevention

Treat synthesized permissions as metadata rather than user activation intent.
Every launch route must honor the filesystem's peer shell contract. Test input
ownership with panels both visible and hidden, and test cancelled downloads
before allowing a local desktop launch.
