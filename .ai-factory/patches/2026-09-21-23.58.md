# Folder thumbnails disappeared after Group by changed the catalog

**Date:** 2026-09-21 23:58
**Files:** internal/panel/media_registry.go; internal/panel/qt_semantic.go; internal/panel/media_registration_test.go; internal/plughost/qt_extui_directory_preview.go; internal/plughost/qt_extui_directory_preview_test.go; third_party/ZoinGallery/MasonryLayoutThumbnails.cpp; third_party/ZoinGallery/tests/MasonryLayoutModesTest.cpp
**Severity:** high

## Problem

Changing `Group by` in a parent directory could make every folder thumbnail
disappear and prevent it from returning. A paged catalog response was treated
as a complete directory-preview authority snapshot, while a layout rewrap
could also publish an empty preview demand during its temporary hidden
geometry pass.

## Root Cause

Catalog grouping advances the semantic catalog revision. The first response
for the new revision is frequently only a viewport-sized page. The directory
preview broker replaced the panel's complete authority set with the IDs seen
in that page, invalidating folders that had not yet been requested. Separately,
`MasonryLayout::updateViewportIndexSets()` interpreted an empty or hidden
viewport during a same-mode rewrap as an explicit cancellation. With folder
cache mode disabled, that retired the preview models and their demand was not
necessarily restored by a later geometry notification.

## Solution

Added `CommitDirectoryPanelPage`, which validates and admits only the current
page while retaining previously admitted panel authorities. The semantic
paging path marks a commit complete only when the response covers the whole
catalog from offset zero; complete commits retain the existing replacement
semantics. Added Go regressions for both the broker and the paging caller.

The Masonry viewport now retains directory-preview demand during an empty or
hidden same-mode layout pass. Explicit non-preview presentation changes still
clear demand. An opt-in `[FIX:directory-preview-page]` debug log and
`[FIX:folder-preview-layout-demand]` media trace identify the protected paths.
Added a Qt regression that reproduces the pre-fix enumeration increase during
a hidden layout rewrap and verifies that no new folder enumeration occurs.

## Prevention

- Distinguish complete catalog authority replacement from viewport-page
  admission at every paged media boundary.
- Treat layout invalidation and explicit preview cancellation as separate
  operations; an empty intermediate viewport must not revoke stable demand.
- Keep regression coverage for grouping revisions, cache-off folder previews,
  and hidden/intermediate layout passes.
- Use the opt-in `[FIX:*]` diagnostics when investigating future preview
  lifecycle regressions.
