# Prevent an extra interpolation after viewer downsampling

**Date:** 2026-09-17 01:37
**Files:** third_party/ZoinGallery/ViewerResampleEffect.{h,cpp}, CMakeLists.txt, qml/ViewerResample.qml, qml/ViewerImageLayer.qml, resources/viewer_resample.{vert,frag}, tests/ViewerResampleGpuTest.cpp, tests/ReusableViewerPrimitivesTest.cpp, tests/StandaloneShellSmokeTest.cpp, README.md
**Severity:** medium

## Problem

At 50% zoom, F4 rendered the same image substantially softer than PictureView
despite matching the reduction kernel. Nominal scene-coordinate alignment
checks passed at 175% display scale.

## Root Cause

A 3840x2076 physical framebuffer uses a rounded 2194x1186 logical window at
DPR 1.75. Their extents differ by half a physical pixel on each axis. The
scene-graph projection therefore stretched the already filtered image slightly:
the nominal image origin (1571,846) became (1571.204584,846.203806) in the
framebuffer. Sampling the half-size texture bilinearly added visible blur.
The exact-texel path previously applied only at native 100% zoom.

## Solution

A small native scene-graph material supplies the active render target's actual
viewport and backend orientation at draw time. Its vertex shader aligns the
final projected rectangle and preserves the intended pixel count at rest,
including quarter turns. Identity sampling follows the selected texture size,
so an exact half/quarter pyramid or prepared fit frame also fetches exact texels.
Active pan, zoom and transitions retain continuous geometry and filtering.
The filter kernel, transfer functions and color-profile handling are unchanged.

The regression failed before the fix by 49 channel levels at pixel (1,0),
although its leaf geometry and unit-transform checks passed. After the fix,
24 offscreen GPU cases pass, including complete image edges, opposite rounding,
oversized/clipped images, rotation and motion-to-rest. The 21 primitive cases,
17 interaction cases, embedded-only QML import check, Windows import audit and
embedded-host extraction tests pass. No visual inspection was performed.

## Prevention

- Check the final render-target projection in addition to nominal DPR times
  scene coordinates; rounded logical window sizes can hide fractional raster
  positions even when every scene-space leaf check passes.
- Compare complete numerical renderings and the transparent perimeter. Exact
  texel fetch alone can conceal duplicated or missing edge texels.
- Cover both framebuffer rounding directions, clipping, quarter turns and
  active motion at fractional DPR.
- Preserve API defaults when replacing a QML effect with a native item:
  default-constructed QSizeF is (-1,-1), not (0,0).
- Isolate alignment from existing filter-policy differences. At 1201x799 to
  601x399 the CPU halves Y independently while the GPU selects shared pyramid
  levels; use an exact-framebuffer GPU reference for that geometry case rather
  than weakening tolerances or silently changing the reduction algorithm.
