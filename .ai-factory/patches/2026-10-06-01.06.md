# Video thumbnails preserve display aspect ratio

**Date:** 2026-10-06 01:06
**Files:** third_party/ZoinGallery/Runners/VideoThumbnailRunner.cpp, FileListModelSignals.cpp, src/embed/ExternalCatalogDecode.cpp, ExternalCatalogMetadata.cpp, ExternalCatalogModel.cpp, ExternalCatalogResetTransaction.cpp, ExternalCatalogThumbnailPlanner.cpp, ThumbnailMemoryCache.cpp, qml/GalleryEntryPreview.qml, related tests and cache transform call sites; qt/host/README.md
**Severity:** medium

## Problem

Portrait videos in CozyPets/PetCareReactionMedia/Videos appeared inside wide
16:9 contact sheets. The example video has display dimensions 1320x2346.

## Root Cause

The temporary 16x9 video metadata placeholder became permanent catalog geometry.
Contact sheets used the requested bounding box as their canvas rather than the
decoded display aspect. Metadata updates reset discovered dimensions. Cache
coverage also assumed decoded pixels filled both requested bounds.

## Solution

Compose sheets within request bounds using display frames, including viewport and
rotation. Carry real dimensions in completed decode requests and apply them through
the model metadata path. Preserve known dimensions through cache deliveries,
metadata patches and catalog resets, and persist source metadata. Use the
video-contact-sheet-2x2-display-v4 transform to regenerate padded sheets and fit
video cache coverage to the actual decoded aspect.

The portrait 175% test exposed a redundant glyph translation: the icon center was
(-1,-1) physical pixels from the badge center. Center the icon locally within the
already aligned badge using compatible physical extents. The origin and transform
assertions and captured renders now pass for landscape, portrait and square tiles.

## Prevention

- Test non-landscape videos with a deliberately mismatched thumbnail request.
- Assert metadata retention across updates, resets and late cached completions.
- Treat pre-probe sizes as provisional and decode target sizes as bounds.
- Change cache transform versions when output geometry changes.
- Check every raster/text leaf and rendered output at fractional DPR.

## Verification

Before the fix, the portrait sheet test returned 320x180 and the model test retained
16x9 after a 90x160 poster. Both pass after the fix, along with cache/poster reuse,
embedded QML import and video controls tests. Landscape/portrait/square scene checks
at DPR 1.75 pass and rendered captions/icons were inspected. Windows DLL audit and
embedded-host extraction tests pass. The packaged Qt application was rebuilt and
restarted on the supplied directory; runtime trace shows real 1320x2346 sources
producing portrait sheets such as 159x284.
