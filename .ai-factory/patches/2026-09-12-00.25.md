# Keep masonry viewport anchors in one coordinate space

**Date:** 2026-09-12 00:25
**Files:** third_party/ZoinGallery/MasonryLayoutRewrap.cpp, third_party/ZoinGallery/tests/MasonryLayoutModesTest.cpp
**Severity:** medium

## Problem

Leaving Photos through `..` and reopening it moved the left panel about 11%
down and highlighted an unrelated visible photograph.

## Root Cause

Live Go and GallerySession traces kept the authoritative cursor at zero.
The native incremental layout captured its viewport anchor using
`indexGeometry()`, which extends the first row over the top padding, but
restored it using the raw brick Y. Each inserted row therefore added the
six-pixel padding again: 251 inserts accumulated 1506 pixels. Subsequent
visible-cursor rewraps had the same mismatch and added another six pixels per
metadata/geometry update. The QML visual
cursor then used a visible replacement while the real cursor was offscreen.
The host presentation transaction persisted that incorrect viewport.

## Solution

Restore both dense masonry anchor paths using the same `indexGeometry()` coordinate
space used to capture them. Keep opt-in `qt.gallery.viewport.rewrap` diagnostics
under `F4_MEDIA_TIMING_TRACE`, marked `[FIX:parent-reentry]`.

The regression exercises three child/parent/reentry cycles and a short-to-full
catalog handoff inside the host-style presentation transaction. Before the
fix, the visible cursor became row 8 despite authoritative cursor zero. After
the fix, the session cursor, native cursor, visual cursor, and zero offset all
remain coherent. A subsequent geometry update independently reproduced a
six-pixel residual drift before the cursor-anchor path was fixed as well.
Run at DPR 1.75 alongside thumbnail convergence coverage. The host bridge
test covers the 48-to-299 row handoff, real Enter actions, and a delayed root
projection; it destroys QML before its bridge/session during teardown.

## Prevention

- Capture and restore an anchor using exactly the same geometry convention.
- Exercise batched host transactions: a later timer can mask a native drift
  in a standalone panel test.
- Check painted cursor and scroll position, not only authoritative state.
- Extend future coverage to live insertion/removal while the viewport is
  partially scrolled within its first row.
