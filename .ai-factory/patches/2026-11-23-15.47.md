# Round thumbnails in the compact gallery layouts

**Date** 2026-11-23 15:47

**Files** `QmlImageProvider.cpp`, `GalleryThumbnailCompactLayer.qml`, `MasonryLayoutModesTest.cpp`

**Severity** low

## Problem

At 175% scaling, the first painted pixel at the thumbnail corner still had the source color in Icons (18, 64), Details (14, 79), and Columns (25, 23).

## Root Cause

The compact image mask was present only in the local ZoinGallery checkout used by `zoin`. The PDF worktree's compact delegate used an unmasked thumbnail.

## Solution

Pass the physical thumbnail slot and window scale to the image provider. Apply the gallery's rounded alpha edge to the returned raster while preserving the source aspect ratio.

## Prevention

Run the compact thumbnail regression at 175%. Verify the painted corner and center colors alongside the raster item's scene origin, dimensions, and unit transform.
